# Andrej Tetkić - Portfolio Website

A minimalist, professional portfolio website showcasing my work as a software developer and AI/ML enthusiast.

## 🌟 Features

- **Minimalist Design**: Clean, black-themed interface focusing on content
- **Responsive Layout**: Optimized for desktop and mobile devices
- **SEO Optimized**: Structured data, meta tags, and semantic HTML
- **Fast Loading**: Optimized images and efficient CSS
- **Project Showcases**: Detailed project pages with interactive galleries
- **Complete Portfolio Sections**:
  - Hero section with contact information and social links
  - About section for personal introduction
  - Experience section with detailed work history
  - Education section for academic background
  - Achievements section for competitions, awards, and recognitions
  - Projects showcase with technologies used
  - Detailed project pages with comprehensive descriptions, screenshots, and technical details
  - Skills organized by categories
  - Footer with navigation and copyright information

## How to Use

### 1. Main Portfolio Page (`index.html`)
Replace all placeholder text in square brackets `[PLACEHOLDER]` with your actual information:
- `[YOUR FULL NAME]` - Your full name
- `[YOUR PROFESSIONAL TITLE]` - Your job title or profession
- `[Brief professional summary]` - 1-2 sentences about what you do
- `[Your City, Country]` - Your location
- `[your.email@example.com]` - Your email address
- `[+1 (555) 123-4567]` - Your phone number
- `[LinkedIn URL]`, `[GitHub URL]`, etc. - Your social media links
- Fill in all experience, education, projects, achievements, and skills sections

### 2. Achievements Section
Add your competitions, awards, and recognitions:
- International competitions (like AI Olympiads)
- Academic honors and awards
- Professional certifications
- Speaking engagements or publications
- Open source contributions

### 3. Detailed Project Pages
Each project has its own dedicated page (`project1.html`, `project2.html`, `project3.html`):
- **Project Overview**: Comprehensive description and context
- **Key Features**: Detailed feature list with explanations
- **Technical Implementation**: Architecture and engineering decisions
- **Challenges & Solutions**: Problem-solving showcase
- **What I Learned**: Reflection and growth mindset
- **Future Improvements**: Forward-thinking and scalability
- **Project Showcase**: Screenshots and visual demonstrations
- **Technical Details Sidebar**: Technologies, timeline, and links

### 4. Customization Tips
- **Adding More Projects**: Create additional `projectX.html` files following the same structure
- **Removing Projects**: Delete unused project files and remove corresponding links from `index.html`
- **Screenshots**: Replace placeholder divs with actual project screenshots
- **Colors**: Modify the color scheme in `styles.css` (main theme uses #000 background, #fff text)
- **Fonts**: Change font families in the CSS file

## Project Detail Pages Features

- **Professional Layout**: Two-column design with main content and sidebar
- **Comprehensive Sections**: Overview, features, technical details, challenges, learnings
- **Visual Showcase**: Grid layout for screenshots and diagrams
- **Navigation**: Easy back-to-portfolio navigation
- **Responsive**: Adapts to all screen sizes
- **Technical Sidebar**: Quick access to project metadata and links

## Best Practices for Project Pages

1. **Be Specific**: Use concrete examples and metrics where possible
2. **Show Problem-Solving**: Highlight challenges and your solutions
3. **Include Visuals**: Add screenshots, diagrams, or mockups
4. **Explain Technical Decisions**: Discuss why you chose certain technologies
5. **Demonstrate Growth**: Show what you learned and how you improved
6. **Keep It Updated**: Regularly update project status and improvements
